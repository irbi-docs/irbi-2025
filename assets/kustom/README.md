# Paket kustomisasi terbit (opsional)

Letakkan berkas `irbi-kustom.js` yang diunduh dari **Studio › Simpan › Terbitkan untuk semua pembaca** di folder
ini, lalu render ulang (`./jalankan.sh render`). Pada situs yang sudah dipublikasikan, cukup salin berkas ke
`_book/assets/kustom/`. Semua pembaca akan melihat perubahan data, tampilan, dan teks dari paket tersebut.

Hapus berkas `irbi-kustom.js` untuk kembali ke data dan tampilan bawaan buku.
